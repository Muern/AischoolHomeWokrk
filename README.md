# 小苹果 · 个人作品集

一个基于原生 HTML / CSS / JavaScript 构建的单页个人作品集网站，采用杂志式排版风格，展示 AI 辅助开发、大语言模型应用与数据可视化方向的项目经历。

## ✨ 功能特性

- **杂志式排版**：三栏分割线栏目结构，首屏 Hero + 精选项目 + 全部作品 + 关于我 + 联系页脚
- **数据驱动渲染**：项目列表由 `js/projects.js` 中的数组统一管理，新增项目无需改动任何页面代码
- **三种版式节奏**：作品列表自动在「大图居左 / 文字居左 / 通栏横幅」三种版式间交替轮换
- **深浅色主题切换**：
  - 导航栏右侧按钮一键切换，背景 / 文字 / 边框全站联动
  - `localStorage` 记住用户选择，刷新不丢失
  - 首次访问自动跟随系统深浅色偏好（`prefers-color-scheme`）
  - `<head>` 内联脚本提前设置主题，避免刷新时白屏闪烁（FOUC）
  - 多标签页间通过 `storage` 事件自动同步
- **交互细节**：导航栏滚动毛玻璃效果、「作品」类别下拉快速定位、滚动显现动效、当前栏目高亮、移动端全屏汉堡菜单
- **响应式布局**：适配桌面端、平板、移动端（1024px / 860px / 560px 三档断点）
- **无障碍支持**：语义化标签、`aria-label` 状态同步、`:focus-visible` 焦点样式、`prefers-reduced-motion` 降级

## 🛠 技术栈

- HTML5（语义化标签）
- CSS3（CSS 变量主题系统、Grid / Flex 布局、`clamp()` 流式字号）
- 原生 JavaScript（ES6+，无任何框架依赖）
